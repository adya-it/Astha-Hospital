# Astha Hospital website

Static site for Astha Hospital & Heart Center, Sultanpur. No build step.

- `index.html` is the whole page.
- `img/` holds the photos and logo.

## Host on GitHub Pages

1. Create a new public repository on GitHub, for example `astha-hospital`.
2. Upload these files to the repository root, keeping the `img` folder.
3. Open Settings, then Pages. Under Build and deployment choose "Deploy from a branch", pick `main` and `/ (root)`, then Save.
4. After a minute the site is live at `https://<your-username>.github.io/astha-hospital/`.

To use your own domain, add it under Settings, then Pages, then Custom domain.
